# 🧠 Brain-Do Bot
### powered by Nikita to папа ❤️

Telegram-бот, который превращает Word-файл с вопросами и ответами в готовую презентацию PowerPoint.

---

## ✨ Что умеет

**Подготовка**
- 📎 Принимает **.docx**, а в Docker-версии ещё **.doc, .rtf, .odt**; кроме того **.txt** и вопросы, **вставленные прямо в сообщение**
- 📁 Берёт файлы с **Яндекс Диска**: свежие сверху, листание, поиск по названию
- 👁 **Предпросмотр**: 3–4 слайда картинками прямо в Telegram ещё до скачивания
- ✏️ **Правка в боте**: исправить вопрос, ответ, зачёт или комментарий, пометить сложным, удалить, не трогая Word
- 🔍 **Проверка пакета**: повторы внутри пакета и с прошлыми пакетами, подозрительные ответы; с ключом Groq ещё опечатки и ошибки в ответах
- 🕘 **История**: последние 10 пакетов, пересобрать одной кнопкой; после перезапуска бот помнит последний файл
- 🖼 **Свой шаблон**: пришли .pptx, 1-й слайд станет образцом вопроса, 2-й образцом ответа

**Слайды**
- 🖼 Картинки из вопросов и комментариев переносятся на слайды
- 📑 Туры («Тур 1», «2 тур»): можно сделать презентацию на один тур
- 🎬 Титульный слайд, разделители туров и финальный «Спасибо за игру!»
- 📝 **Заметки ведущего**: ответ, зачёт и комментарий видны в режиме докладчика, залу не видны
- ❓ Текст вопроса мелко на слайде ответа, чтобы зал вспомнил, о чём был вопрос
- ⬜⬛ Белая и тёмная темы; 🔢 нумерация 1, 2, 3… / как в файле / без номеров; 🔀 перемешивание; ★ сложные вопросы
- 📄 PDF-версия одной кнопкой (нужен LibreOffice, он есть в Docker-образе)

**Для игры**
- 📊 **Таблица результатов** (Excel): команды × вопросы, суммы по турам, итог и места считаются сами
- 🖨 **Раздатка** (Word): картинки и «Раздаточный материал» каждого вопроса на отдельной странице

**Удобство и надёжность**
- ⚙️ Запоминает настройки; ⚡ быстрый режим делает презентацию сразу после загрузки
- 🔒 Закрытый режим: пускать только по одобрению админа или по приглашению
- ⚠️ Ошибки бота приходят админу в Telegram
- 🤖 ИИ-помощник (Llama 4 через Groq) видит последний загруженный файл
- ✅ Автотесты на GitHub при каждом изменении

## 📄 Формат файла

Пиши как удобно, главное, чтобы у каждого вопроса был ответ:

```
Тур 1

Вопрос 1: Кто написал «Войну и мир»?
Ответ: Лев Толстой
Зачёт: Толстой
Комментарий: Написал в 1869 году.
Источник: Википедия

2. * Назовите столицу Мозамбика. [Раздаточный материал: Мапуту — Maputo]
Ответ:
Мапуту
```

- Номер вопроса: «Вопрос 5», «5.», «5)» или нумерованный список Word
- Ответ можно перенести на следующую строку
- Вопросы в таблицах тоже находятся
- `*` в начале вопроса означает сложный вопрос (на слайде будет ★)
- `[Раздаточный материал: …]` попадает в файл раздатки
- Строки «Источник», «Автор», «Редактор» пропускаются
- Если в нумерации есть дыры, бот просит ИИ проверить, не пропущено ли что-то. ИИ возвращает только координаты, а текст берётся из файла дословно.

### Свой шаблон оформления
Обычная презентация .pptx: **1-й слайд** — образец вопроса, **2-й** — образец ответа. Самое большое текстовое поле станет местом для текста, а поле с текстом «Вопрос 1» (если есть) будет номером. Фон, шрифты и картинки берутся из шаблона. Вернуть стандартное оформление можно в ⚙️ Настройках.

## 🚀 Запуск

### Локально
```bash
pip install -r requirements.txt
export BOT_TOKEN="токен от @BotFather"
python bot.py
```

### Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен бота от @BotFather |
| `ADMIN_IDS` | | Telegram ID админов через запятую. Свой ID покажет команда `/id`. Админам приходят ошибки и запросы доступа |
| `ACCESS_MODE` | | `open` (по умолчанию) — бот для всех; `private` — только админы и одобренные ими |
| `GROQ_API_KEY` | | Ключ Groq для ИИ-чата, проверки пропусков и проверки пакета |
| `GROQ_MODEL` | | Модель Groq (по умолчанию Llama 4 Scout) |
| `YADISK_CLIENT_ID`, `YADISK_CLIENT_SECRET` | | OAuth-приложение Яндекса |
| `PUBLIC_URL` | | Публичный адрес бота для OAuth (по умолчанию адрес на Railway) |
| `DATA_DIR` | | Папка для статистики, настроек, истории, шаблонов и токенов (в Docker — `/data`) |

### Закрытый режим
1. Напиши боту `/id`, добавь число в `ADMIN_IDS`
2. Поставь `ACCESS_MODE=private`
3. Новые люди жмут «🙋 Попросить доступ», тебе приходит запрос с кнопками «Пустить / Отказать»
4. Или отправь им ссылку из `/invite` (одноразовая, живёт 7 дней)
5. `/users` — список одобренных; нажми на человека, чтобы закрыть ему доступ

### Railway (рекомендуется)
1. Deploy from GitHub: Railway сам соберёт `Dockerfile`
2. Добавь переменные окружения из таблицы
3. **Подключи Volume с путём `/data`**, иначе статистика, настройки, история, шаблоны и вход в Яндекс Диск сбрасываются при каждом деплое
4. В настройках OAuth-приложения Яндекса Redirect URI: `<PUBLIC_URL>/yadisk/callback`

## 🧪 Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Тесты проверяют парсер, генератор, предпросмотр, таблицу, раздатку, историю, доступ и сценарии бота целиком на подставном Telegram (`tests/fakes.py`). На GitHub они запускаются автоматически (`.github/workflows/tests.yml`).

## 🗂 Структура

| Файл | Что внутри |
|---|---|
| `bot.py` | Точка входа, веб-сервер для OAuth и health check |
| `handlers.py` | Диалог: файлы, карточка, генерация, предпросмотр, Яндекс Диск, ИИ |
| `editor.py` | Список вопросов и правка |
| `admin.py` | Закрытый доступ, приглашения, ошибки админам |
| `session.py` | Общее состояние и утилиты обработчиков |
| `keyboards.py` | Кнопки |
| `parser.py` | Разбор документа на вопросы |
| `generator.py` | Раскладка вопросов по слайдам и сборка .pptx из шаблона |
| `preview.py` | Предпросмотр слайдов картинками |
| `extras.py` | Таблица результатов и раздатка |
| `review.py` | Проверка пакета |
| `history.py` | История пакетов |
| `access.py` | Кто может пользоваться ботом |
| `office.py` | Конвертация через LibreOffice (.doc→.docx, .pptx→.pdf) |
| `yadisk.py` | API Яндекс Диска |
| `storage.py` | Статистика и токены (JSON в `DATA_DIR`) |
| `config.py` | Все настройки |
