# 🧠 Brain-Do Bot
### powered by Nikita to папа ❤️

Telegram-бот, который превращает Word-файл с вопросами и ответами в готовую презентацию PowerPoint.

---

## ✨ Что умеет

- 📎 Принимает **.docx**, а в Docker-версии ещё **.doc, .rtf, .odt**; кроме того **.txt** и вопросы, **вставленные прямо в сообщение**
- 📁 Берёт файлы с **Яндекс Диска**: свежие сверху, листание, поиск по названию
- 🖼 Переносит **картинки** из вопросов и комментариев на слайды
- 📑 Понимает **туры** («Тур 1», «2 тур»): можно сделать презентацию на один тур
- ⬜⬛ Белая и тёмная темы (в тёмной логотип тоже светлый)
- 🔢 Нумерация: 1, 2, 3… / как в файле / без номеров
- 🔀 Перемешивание вопросов, ★ пометка сложных
- 📄 PDF-версия одной кнопкой (нужен LibreOffice, он есть в Docker-образе)
- ⚙️ Запоминает настройки; ⚡ быстрый режим делает презентацию сразу после загрузки
- 🔁 Можно пересобрать с другими настройками без повторной загрузки файла
- 🤖 ИИ-помощник (Llama 4 через Groq) видит последний загруженный файл
- 📊 Общая и личная статистика

---

## 📄 Формат файла

Пиши как удобно, главное, чтобы у каждого вопроса был ответ:

```
Тур 1

Вопрос 1: Кто написал «Войну и мир»?
Ответ: Лев Толстой
Зачёт: Толстой
Комментарий: Написал в 1869 году.
Источник: Википедия

2. * Назовите столицу Мозамбика.
Ответ:
Мапуту
```

- Номер вопроса: «Вопрос 5», «5.», «5)» или нумерованный список Word
- Ответ можно перенести на следующую строку
- Вопросы в таблицах тоже находятся
- `*` в начале вопроса означает сложный вопрос (на слайде будет ★)
- Строки «Источник», «Автор», «Редактор» пропускаются
- Если в нумерации есть дыры, бот просит ИИ проверить, не пропущено ли что-то. ИИ возвращает только координаты, а текст берётся из файла дословно.

## 🚀 Запуск

### Локально
```bash
pip install -r requirements.txt
export BOT_TOKEN="токен от @BotFather"
python bot.py
```

### Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен бота от @BotFather |
| `GROQ_API_KEY` | | Ключ Groq для ИИ-чата и проверки пропусков |
| `GROQ_MODEL` | | Модель Groq (по умолчанию Llama 4 Scout) |
| `YADISK_CLIENT_ID`, `YADISK_CLIENT_SECRET` | | OAuth-приложение Яндекса |
| `PUBLIC_URL` | | Публичный адрес бота для OAuth (по умолчанию адрес на Railway) |
| `DATA_DIR` | | Папка для статистики, настроек и токенов (в Docker — `/data`) |

### Railway (рекомендуется)
1. Deploy from GitHub: Railway сам соберёт `Dockerfile`
2. Добавь переменные окружения из таблицы
3. **Подключи Volume с путём `/data`**, иначе статистика, настройки и вход в Яндекс Диск сбрасываются при каждом деплое
4. В настройках OAuth-приложения Яндекса Redirect URI: `<PUBLIC_URL>/yadisk/callback`

## 🗂 Структура

| Файл | Что внутри |
|---|---|
| `bot.py` | Точка входа, веб-сервер для OAuth и health check |
| `handlers.py` | Логика диалога: файлы, карточка, генерация, Яндекс Диск, ИИ |
| `keyboards.py` | Кнопки |
| `parser.py` | Разбор документа на вопросы |
| `generator.py` | Сборка .pptx из `template.pptx` |
| `office.py` | Конвертация через LibreOffice (.doc→.docx, .pptx→.pdf) |
| `yadisk.py` | API Яндекс Диска |
| `storage.py` | Статистика и токены (JSON в `DATA_DIR`) |
| `config.py` | Все настройки |
