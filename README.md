# 🧠 Brain-Do Bot
### powered by Nikita to папа ❤️

Telegram-бот который превращает Word-файл с вопросами/ответами в готовую презентацию PowerPoint.

---

## 📦 Установка

### 1. Установи Python 3.10+
Скачай с https://python.org если ещё нет.

### 2. Скачай папку бота
Положи всю папку `brain_do_bot` куда удобно, например:
```
C:\Users\ИМЯ\Desktop\brain_do_bot\
```

### 3. Установи зависимости
Открой терминал в папке бота и выполни:
```bash
pip install -r requirements.txt
```

---

## 🔑 Настройка токена

Открой файл `bot.py` в любом текстовом редакторе.

Найди строку:
```python
token = os.environ.get("BOT_TOKEN")
```

Замени на:
```python
token = "СЮДА_ВСТАВЬ_СВОЙ_ТОКЕН"
```

Токен берёшь у @BotFather в Telegram.

---

## 🚀 Запуск

```bash
python bot.py
```

Бот запущен! Теперь можно писать ему в Telegram.

## 📄 Формат Word-файла

В документе должны быть слова **Вопрос** и **Ответ**.
Комментарий — необязателен.

Пример:
```
Вопрос 1: Кто написал «Войну и мир»?
Ответ: Лев Толстой
Комментарий: Написал в 1869 году.

Вопрос 2: ...
```

### Сложный вопрос
Добавь `*` в начало текста вопроса — он будет выделен красным:
```
Вопрос 3: * Назовите столицу Мозамбика.
```

## ☁️ Запуск на сервере (чтобы бот работал постоянно)

### Бесплатный хостинг — Railway.app

1. Зарегистрируйся на https://railway.app
2. Создай новый проект → Deploy from GitHub
3. Загрузи папку бота на GitHub
4. В настройках Railway добавь переменную окружения:
   - `BOT_TOKEN` = твой токен
5. Готово — бот работает 24/7!

### Альтернатива — Render.com
Аналогично, бесплатный план тоже подойдёт.
